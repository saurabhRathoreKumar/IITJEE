```
70% - Solve problems at JEE Main difficulty (speed + accuracy)

```

```
  ✓ Category tracking (to identify patterns)
  
Maintain: MISTAKE TRACKER SHEET
  - Problem ID
  - Topic
  - Type of error
  - Difficulty level
  - Date of error
  - Date of revision
```

## 🎓 LEARNING PHILOSOPHY FOR JEE SUCCESS

### The Three-Tier Problem-Solving Approach

```
TIER 1: RECOGNITION (Can you identify the concept?)
  - Given a problem, identify which chapter/concept it uses
  - Time: 10-15 seconds
  - Goal: 95%+ accuracy
  - Method: Exposure to 200+ problems per chapter

TIER 2: EXECUTION (Can you solve it using standard approach?)
  - Apply standard formulas, methods, theorems
  - Time: 1-3 minutes depending on complexity
  - Goal: 85%+ accuracy (some computational errors acceptable)
  - Method: Practice 100+ problems with full solutions

TIER 3: OPTIMIZATION (Can you solve it using best approach?)
  - Use shortcuts, clever tricks, alternative methods
  - Time: <1 minute for standard problems
  - Goal: 90%+ accuracy with speed
  - Method: Practice 50+ problems with advanced techniques
```

### The Learning Sequence

```
1. CONCEPTUAL UNDERSTANDING (20% effort)
   - Read theory 2-3 times
   - Watch solved examples
   - Understand "why", not just "how"

2. GUIDED PRACTICE (30% effort)
   - Solve examples from textbook/coaching material
   - Follow step-by-step solutions
   - Understand each step

3. INDEPENDENT PRACTICE (40% effort)
   - Solve problems without seeing solutions
   - Make mistakes (this is where learning happens)
   - Review solutions only after attempting
   - Understand where you went wrong

4. COMPETITIVE PRACTICE (10% effort)
   - Solve under time pressure
   - Develop speed and accuracy
   - Participate in mock tests
```
